# Sprint 2 人工验收清单

> 交付物：划词取义功能 —— 选中文本后右下角显示**粉色圆点指示器**，点击圆点展开翻译卡片。

> - **单词模式**（≤3 词）：显示单词标题 + 词性/释义 + 上下文解释
> - **段落模式**（长文本）：上方灰色背景显示原文 + 下方加粗显示中文翻译

## 手动验收步骤（需要人工执行）

### 1. 重新加载扩展

`chrome://extensions` → Twin Read 卡片点 ↻（重要：background/content 已更新）

### 2. 基础划词用例

打开任意英文网页（如 GitHub README、Wikipedia）

- 双击选中一个单词（如 `bank`、`cell`、`pitch` 这类多义词）
- **预期**：选区右下角出现**粉色小圆点**（~20px，颜色 #e84393）
- 点击圆点 → 卡片展开，先显示「正在结合上下文翻译…」，数秒后显示结果

### 3. 单词模式验证

- 选中单个单词（如 `deliberately`）
- **预期卡片内容**：
  - 顶部：单词标题（加粗，如 **deliberately**）
  - 下方：词性 + 中文释义（如 `adv. 故意地；蓄意地`）
  - 再下方：在该上下文中的具体含义解释

### 4. 段落模式验证

- 选中一整段或长句（>3 词）
- **预期卡片内容**：
  - 上方：浅灰色背景框显示**原文**
  - 下方：加粗显示**中文翻译**

### 5. 上下文敏感性验证（核心 Proof）

- 在财经新闻里选中 `bank` → 预期释义偏向「银行」
- 在技术文档里选中 `bank` → 预期释义偏向「（数据）库/存储组」等语境化解释

### 6. 样式隔离验证（ADR-003）

- 在样式复杂的网站（GitHub dark mode、Reddit）划词
- **预期**：卡片外观完全一致（白底/深色模式自适应、圆角、阴影），不被宿主 CSS 破坏
- 宿主页面无被注入的杂散元素（卡片内部节点对外 `.shadowRoot === null`）

### 7. 关闭交互验证

- 显示卡片后点击页面空白处 → 卡片消失
- 再次划词 → 圆点重新出现 → 点击圆点 → 卡片重新展开
- 显示卡片后按 `Esc` → 卡片消失
- 页面滚动 → 卡片消失（避免定位失效）
- 选区位于视口底部 → 卡片自动翻转到选区上方

### 8. 错误路径用例

- 暂时把 API Key 改错并保存，再划词并点击圆点
- **预期**：卡片内显示红色错误信息（如 HTTP 401），而非空白、卡死或无响应
- 验完改回正确 Key

### 9. 边界用例

- 选中超过 300 字符的大段文本 → **预期不出现圆点**（留给整页翻译）
- 双击 input/textarea 内的文本 → 预期不出现圆点
- 划词翻译期间点击链接 → 页面行为正常（content 未破坏宿主交互）

## 边界确认（架构不越界）
